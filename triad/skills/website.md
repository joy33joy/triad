Website: building a clean, fast static website or small web app.
- Default to plain HTML/CSS/JS (no build step) unless the project needs a framework.
- Mobile-first, accessible (semantic HTML, alt text, contrast), works offline when opened from disk if possible.
- One shared stylesheet and consistent components; keep data in a separate JSON file the page loads.
- Check it in a browser or with a quick local server (python3 -m http.server) before calling it done.
